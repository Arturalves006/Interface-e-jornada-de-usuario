#### 3° Passo (Criação de uma IA com wireframe de alta fidelidade)
 Aria - Assistente Inteligente para Triagem Hospitalar

Sobre o Projeto

Aria é uma inteligência artificial conceitual desenvolvida para auxiliar o processo de triagem hospitalar, tornando o atendimento mais eficiente diante dos desafios causados pela superlotação dos hospitais.

A solução foi projetada para apoiar enfermeiros e médicos durante o fluxo de atendimento, coletando informações dos pacientes, analisando sintomas e gerando um pré-diagnóstico com nível de confiança. As informações são então encaminhadas ao médico responsável, que pode validar ou ajustar a análise antes da continuidade do atendimento.

O projeto foi desenvolvido como parte de uma atividade acadêmica focada em arquitetura da informação, experiência do usuário (UX), design de interface e prototipação de soluções digitais com inteligência artificial.
